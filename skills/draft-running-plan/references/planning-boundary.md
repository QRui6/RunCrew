# 规划规则边界

## 外部原则

- WHO《身体活动和久坐行为指南》给出成年人总体身体活动建议，但不是针对个人目标成绩的跑步课表处方：<https://www.who.int/publications/i/item/9789240015128>
- NHS Couch to 5K 使用循序推进、每周三次和跑步之间安排休息日的入门结构：<https://www.nhs.uk/better-health/get-active/get-running-with-couch-to-5k/couch-to-5k-running-plan/>

这些资料只支持 RunCrew 的高层安全原则，不能据此断言某个用户的最佳周跑量、配速或伤病风险。

## RunCrew v1 工程规则

以下规则为了可解释、可回放和保守失败而设计，不是医学标准：

- 草案最多选择三个用户可训练日，并最大化相邻训练日的最小间隔；
- 至少 3 条近期活动且历史周均时长达到 45 分钟，才认为时长基线可用；
- 基线可用时，草案周时长最多按历史周均增加 5%，并取整到 5 分钟；
- 基线不足时，一至三个训练日分别使用 30、60、70 分钟的总时长模板；
- 三课时长按 30% / 30% / 40%，两课按 40% / 60% 分配；
- 至少 8 条近期活动、有 3 个训练日且距离目标日不少于 28 天时，才允许一节受控节奏课；
- `reduce` 把原距离和时长降到 60%，改为 recovery，并移除速度目标；
- 比赛周不自动规划，交由用户或具备更完整比赛策略能力的后续版本处理。

## 已知限制

- v1 不理解海拔、气温、赛道、力量训练、女性生理周期、跨项目负荷或医生建议；
- v1 不依据目标成绩生成配速区间；
- 训练时长基线尚未按运动类型之外的重复来源自动去重，应显式指定 Provider；
- 计划结果是草案，不构成医疗许可或专业教练处方。
