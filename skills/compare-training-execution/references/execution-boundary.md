# 执行对照规则边界

## 规则目的

训练执行匹配是数据关联问题，不是运动医学或训练质量判定。规则优先保证可解释、可回放和可纠正。

## RunCrew v1 规则

- 只匹配四类规范化跑步活动；
- 默认候选窗口为计划日前后一天，最大不超过三天；
- 候选得分：日期接近度 55%，可比较训练量相似度 45%；
- 只有日期而没有可比较距离或时长时，最高得分不超过 0.65，不能形成清晰完成结论；
- 最佳得分低于 0.65、前两候选分差小于 0.15，或同一活动是多节课的最佳候选时，标记 ambiguous；
- 距离与时长都存在时，完成比例取两者的较低值；达到 90% 标记 complete，否则标记 partial；
- unmatched 不自动转换为 skipped；skipped 只由用户确认；
- 已确认执行、跳过和清除都会提升 plan revision，并留下独立审计记录。

## 已知限制

- 不读取运动标题自由文本来猜测“间歇”“节奏”等训练类型；
- 不比较配速区间、心率区间、分段结构、海拔路线和主观完成质量；
- 不自动解决多设备或多 Provider 的同一次活动重复记录；
- 当前重复活动约束只覆盖同一训练计划，跨计划冲突留给后续 Orchestrator；
- confirmed 表示用户确认的数据关联，不表示训练达到专业教练定义的训练效果。
